# 📱 모바일 생생세특 (Live Seteuk) v2.0 - 교사 공유 패키지

> **"선생님께 가장 익숙한 '진짜 구글 시트'에 학생 명단을 엑셀처럼 1초 만에 복사해서 붙여넣고, 스마트폰 음성으로 생생하게 기록하여 NEIS 300자 세특으로 완성합니다."**

---

## 🌟 핵심 기능 요약

1. **💚 진짜 구글 시트 (Google Spreadsheet) 중심 설계**
   - 가짜 웹 에디터 화면을 전면 축출하고 교사들에게 100% 익숙한 **진짜 구글 시트 파일**을 중심축으로 설정
   - 나이스(NEIS) 또는 엑셀 학생 명단을 **`Ctrl+C` -> `Ctrl+V`로 [학생명렬] 탭에 1초 만에 복사·붙여넣기 완료**

2. **📱 휠 터치 0.3초 스마트폰 음성 관찰기 (`app.html`)**
   - 5분할 휠(교과, 행특, 자율, 진로, 동아리) 터치 후 즉시 녹음
   - 0.3초 초고속 정규식 파싱으로 학번/이름 자동 분류 및 시트 즉시 저장
   - Web Speech API 및 AI 실시간 관찰 코칭 팁 기능 탑재

3. **🖥️ PC 대시보드 (`dashboard.html`)**
   - 실시간 관찰 타임라인 및 학번/이름 검색 필터 모아보기
   - 2022 개정 교과역량 & 목표 바이트(900 Bytes / 300자 표준) 컨트롤 패널
   - 클릭 한 번으로 나이스 업로드용 `NEIS_세특초안.csv` 다운로드

4. **🔮 5명 15초 대기 & 스마트 Diff 캐싱 (할루시네이션 0%)**
   - 5명 생성 시마다 15초 자동 대기(API 쿼터 안전 및 시간초과 예방)
   - 변경 없는 학생 기존 세특 100% 유지

---

## 📂 파일 구성 (총 4개)

- **`Code.gs`**: 백엔드 서버 로직 및 구글 시트 상단 `📱 모바일 생생세특 v2.0` 메뉴 연동
- **`app.html`**: 스마트폰 음성 관찰기 PWA 앱
- **`dashboard.html`**: PC 대시보드 및 NEIS CSV 다운로드 뷰
- **`TEACHER_TRAINING_GUIDE.md`**: 개학 후 교사 연수용 가이드라인 & 카카오톡 공유 문구

---

## 🚀 교사 사용 3단계 가이드

1. **[진짜 구글 시트 열기]**: 시트 상단 메뉴 `[📱 모바일 생생세특 v2.0]` -> `[2. 📋 시트 7대 탭 자동 양식 세팅]` 클릭 (7대 탭 1초 완성)
2. **[학생 명단 복사]**: [학생명렬] 탭에 나이스/엑셀 명단 `Ctrl+V` 붙여넣기
3. **[스마트폰 음성 입력 & 세특 완성]**: 핸드폰 앱 주소 접속 후 음성 녹음 ➔ PC 대시보드에서 300자 세특 완성 및 CSV 다운로드!
