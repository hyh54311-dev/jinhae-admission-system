# 📱 모바일 생생세특 (Live Seteuk) v2.0 - 현장 관찰 & AI 세특 패키지

본 패키지 **모바일 생생세특(Live Seteuk)**은 **"현장의 생생한 관찰 기록을 라이브로 담아 나이스 세특으로 완성하는 교사 전용 스마트 AI 패키지"**로, 교사의 수업 중 음성 관찰 기록을 스마트폰 PWA로 0.3초 만에 수집하고, **2022 개정 교육과정 교과 핵심역량**과 **선생님별 NEIS 목표 바이트 수(500B / 750B / 1000B / 1500B)**를 직접 선택하여 완벽한 생활기록부를 완성하는 교사 전용 풀스택 웹앱 패키지입니다.

---

## 📂 패키지 구성 파일 (총 6개)

1. `Code.gs`
   - 2022 개정 교과역량 & NEIS 목표 바이트 수 반영 Gemini / Upstage API 백엔드
   - `PropertiesService` 구글 서버 암호화 보안 금고 기반 API 키 관리
2. `dashboard.html`
   - 교사용 대시보드 (`?view=dashboard`)
   - 1~10반 선택 탭 + 실시간 학번/이름 검색 + 2022 교과역량 연계 + 바이트(500B/750B/1000B/1500B) 선택 UI
3. `app.html`
   - 스마트폰 PWA 음성 앱 (`app.html`)
   - 5분할 원형 휠 + 1초 마이크 오토포커스 + 학번/이름 AI 자동 파싱
4. `sheet.html`
   - 웹 브라우저 내 구글 시트 데이터 인터랙티브 편집 라이브 뷰
5. `TEACHER_TRAINING_GUIDE.md`
   - 개학 후 교사 연수용 10분 가이드라인 + 카카오톡/단톡방 공유용 안내 메시지 템플릿
6. `README.md`
   - 관리자 및 개발자 배포 설명서

---

## 🔒 보안 특징
- 개인 API Key 및 학생 개인정보가 코드에 전혀 하드코딩되어 있지 않습니다.
