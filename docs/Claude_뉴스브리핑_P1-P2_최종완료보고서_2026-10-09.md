## 1. P1: 프로젝트 전수 SSL 검증 정상화 & Windows OS 신뢰 저장소 연동

### 1.1. 원인 규명
- **배경:** 경상남도교육청 학내망 보안 게이트웨이는 HTTPS 통신 시 교육청 자체 루트 인증서(`GNE_CERT`)를 통해 SSL 트래픽을 중계합니다.
- **기존 문제:** Python의 `requests` 및 `urllib`는 Mozilla CA 번들(`certifi`)을 기본 사용하므로, OS에 정상 설치된 `GNE_CERT`를 인식하지 못해 `SSLError`가 발생했습니다. 이로 인해 과거 작성된 스크립트들이 `verify=False`, `urllib3.disable_warnings()`, `ssl.CERT_NONE`, `check_hostname = False` 등의 임시 우회 방식을 프로젝트 전반에 산발적으로 도입하게 되었습니다.

### 1.2. 근본 해결: `truststore` 전역 연동
- Python 3.10+ 표준 호환 라이브러리인 `truststore`를 활용하여 Python SSL 컨텍스트가 **Windows 네이티브 CryptoAPI Root Certificate Store**를 직접 참조하도록 전환했습니다.
- 스크립트 진입부 및 최상단 실행기(`run_job.py`)에 아래 표준 블록을 적용:
  ```python
  try:
      import truststore
      truststore.inject_into_ssl()
  except Exception:
      pass
  ```
- **효과:** `requests`, `urllib`, `http.client` 등 모든 네트워크 호출이 Windows OS 신뢰 인증서(`GNE_CERT` 포함)를 기반으로 정식 SSL 무결성 검증(`verify=True`)을 수행하게 되었으며, 보안 취약점인 검증 무력화 코드(`verify=False`, `CERT_NONE` 등)를 전수 제거했습니다.

## 2. P2: 종목코드 필터 정밀화 & 주요 경제 뉴스 100% 보존

### 2.1. 문제점
- 연합뉴스는 상장사 관련 기사 제목에 상시적으로 6자리 종목코드(예: `삼성전자[005930]`)를 표기합니다.
- 기존 로직에서 종목코드 정규식(`\[\d{6}\]`)을 무조건 잡음으로 차단함에 따라, `삼성전자[005930] 3분기 영업이익 107조원…사상 최대`와 같은 핵심 경제 뉴스가 탈락하는 부작용이 발생했습니다.

### 2.2. 해결 규칙 (`news_briefing_bot.py` 반영)
1. **종목코드 단독 차단 해제:** 종목코드 존재 자체만으로는 기사를 차단하지 않습니다.
2. **보도자료/홍보 복합 조건화:**
   - 종목코드(`\[\d{6}\]`)가 존재하면서,
   - 단순 제품/이벤트 홍보 키워드(`한정 판매`, `협업`, `컬렉션`, `팝업`, `출시`, `선보여`, `기념`, `입점`, `신제품`, `이벤트`)를 포함하고,
   - 거시경제/실적 핵심 키워드(`실적`, `영업이익`, `매출`, `수출`, `투자`, `관세`, `인수`, `합병`, `공시`)를 포함하지 않는 경우에만 차단합니다.
